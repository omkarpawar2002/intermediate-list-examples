# Intermediate List Examples

This repository contains Python examples that cover intermediate-level concepts and use-cases of Python lists.

## 📂 Files Included

- `List Methods.py`: This file contains examples of commonly used Python list methods. 
- `List examples.py`: Practical programs showing various list operations like:
  - Adding/removing items
  - Searching and indexing
  - List slicing and iteration
  - Counting and filtering elements
  - Nested list handling
  - Sum of even/odd items, etc.

## 🧠 Topics Covered

- Built-in list methods (`append()`, `remove()`, `sort()`, etc.)
- Conditional filtering with loops
- List slicing and comprehensions
- Working with user input and list processing

These examples are intended to help learners reinforce their knowledge of lists through hands-on coding.
